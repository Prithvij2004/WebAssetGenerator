# Web Asset Generator

## Project Overview

An AI-powered web application that helps developers generate and customize web assets including icons, logos, and sound effects. Users can create projects with specific themes and interact with AI to generate assets that match their vision.

## Core Features

- **Project Management**: Create and manage multiple asset generation projects
- **Theme-Based Generation**: Define themes for projects to guide AI asset generation
- **AI Chat Interface**: Conversational interface to create and refine assets
- **Asset Types**:
  - Icons
  - Logos
  - Sound effects/music
- **Logo Editing**: Minimal manual editing interface for generated logos

## Tech Stack

### Frontend
- **Language**: JavaScript (ES6+)
- **UI Framework**: shadcn/ui
- **Styling**: Tailwind CSS (comes with shadcn)

### AI & APIs
- **Gemini API**: Logo and icon generation
- **Nano Banana API**: Logo editing capabilities
- **ElevenLabs API**: Sound effect and audio generation

## Design Philosophy

**Brutal Minimalism**

The entire application follows a brutal minimalistic design approach:
- Clean, stark interfaces
- High contrast
- Monospace or geometric fonts
- Minimal use of decorative elements
- Focus on functionality over aesthetics
- Sharp edges and geometric shapes
- Limited color palette (typically blacks, whites, and one accent color)
- Clear visual hierarchy
- No unnecessary animations or transitions
- Direct, unpolished aesthetic

## API Integration

### Gemini API
- **Purpose**: Generate logos and icons based on text prompts
- **Usage**: Convert user themes and descriptions into visual assets
- **Key Features**: Multi-modal understanding, creative generation

### Nano Banana API
- **Purpose**: Logo editing and manipulation
- **Usage**: Apply minimal edits to generated logos
- **Operations**: Color adjustments, size modifications, simple transformations

### ElevenLabs API
- **Purpose**: Generate sound effects and audio assets
- **Usage**: Create UI sounds, notification tones, and thematic audio
- **Key Features**: High-quality audio synthesis, customizable parameters

## Development Guidelines

### Code Style
- Use ES6+ features (arrow functions, destructuring, etc.)
- Prefer functional components over class components
- Use async/await for asynchronous operations
- Keep components small and focused
- Follow single responsibility principle

### File Naming
- Components: PascalCase (e.g., `ChatInterface.jsx`)
- Utilities: camelCase (e.g., `apiHelpers.js`)
- Constants: UPPER_SNAKE_CASE (e.g., `API_ENDPOINTS.js`)

### State Management
- Use React hooks (useState, useContext) for local state
- Consider Context API for global state (projects, user settings)
- Keep API calls in separate service files

### Error Handling
- Always handle API errors gracefully
- Provide user-friendly error messages
- Log errors for debugging
- Implement retry logic for failed API calls

## Key Features Implementation

### 1. Project Creation
- User creates a new project
- Defines project name and theme description
- Theme guides all asset generation within the project

### 2. Chat Interface
- Conversational UI for asset requests
- Natural language processing via Gemini
- Context-aware responses based on project theme
- Display generated assets inline

### 3. Asset Generation

**Logos/Icons (Gemini)**:
```javascript
// Example workflow
const generateLogo = async (prompt, theme) => {
  const enhancedPrompt = `${theme} themed logo: ${prompt}`;
  const result = await geminiAPI.generate(enhancedPrompt);
  return result;
};
```

**Sound Effects (ElevenLabs)**:
```javascript
// Example workflow
const generateSound = async (description, theme) => {
  const soundPrompt = `${description} with ${theme} characteristics`;
  const audio = await elevenlabsAPI.generate(soundPrompt);
  return audio;
};
```

### 4. Logo Editor
- Minimal editing interface (brutal minimalistic)
- Use Nano Banana API for transformations
- Limited to essential edits: color, size, rotation
- No complex photo-editing features

## User Workflow

1. **Start**: User lands on homepage
2. **Create Project**: Click "New Project", enter name and theme
3. **Chat Interface**: Opens chat for the project
4. **Request Asset**: "Create a logo for a coffee shop"
5. **AI Generation**: Gemini processes request, generates logo
6. **Display**: Logo shown in chat with edit/download options
7. **Edit** (optional): Click edit, make minimal adjustments via Nano Banana
8. **Download**: Save asset to local machine
9. **Repeat**: Continue generating more assets in same project

## Best Practices

1. **Keep It Minimal**: Resist adding unnecessary features
2. **Brutal Consistency**: Maintain design language throughout
3. **Fast Generation**: Optimize API calls, show loading states
4. **Local Storage**: Save project data locally for persistence
5. **Asset Management**: Organize generated assets by project
6. **Error Recovery**: Always provide fallback UI states
7. **Accessibility**: Maintain keyboard navigation and screen reader support
